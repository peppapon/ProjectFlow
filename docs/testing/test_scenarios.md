## 1. Введение

Данный документ содержит описание тестовых наборов и сценариев для проверки функциональности информационной системы ProjectFlow.

## 2. Структура тестирования

### 2.1. Уровни тестирования

1. **Unit-тесты (модульные)** - тестирование отдельных функций и методов
2. **Integration-тесты (интеграционные)** - тестирование взаимодействия модулей
3. **E2E-тесты (сквозные)** - тестирование полных пользовательских сценариев

### 2.2. Инструменты тестирования

- **pytest** - фреймворк для тестирования
- **pytest-cov** - измерение покрытия кода
- **pytest-mock** - создание mock-объектов
- **Flask test client** - тестирование API endpoints

12. Проверить что задача появляется в отчёте по проекту
